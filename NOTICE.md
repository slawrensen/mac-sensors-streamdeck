## Settings panel components and icons

The settings panels load sdpi-components v4.0.1 (MIT, Corsair Memory Inc. and other contributors, <https://sdpi-components.dev>) from `ui/sdpi-components.js`, which bundles Lit (BSD-3-Clause, Google LLC, <https://lit.dev>). The panels also draw Lucide icons (ISC, Lucide Icons and Contributors, <https://lucide.dev>): the Open all and Fold all buttons use Lucide's `chevrons-up-down` and `chevrons-down-up`, the sensor list's Reload button uses `rotate-cw`, and the Default theme chip's link mark is Lucide's `link`, which Lucide derives from Feather (MIT, Cole Bemis). The path data is copied into the panel files. The four licenses follow.

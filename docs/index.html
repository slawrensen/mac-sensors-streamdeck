Mac Sensors

Read available temperatures, fan speeds, power and system activity on your Stream Deck.

Mac Sensors is being built and qualified. There is no release package yet.

Requirements

  • A Mac running macOS 13.5 or later.
  • Stream Deck 7.1 or later, which supplies the Node 24 runtime.
  • Tahoma Bold for measurement faces. If it is unavailable, the plugin shows setup guidance.

Available readings depend on the Mac and macOS version. The plugin only reads hardware; it does not change hardware settings or control fans.
